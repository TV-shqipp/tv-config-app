# Icon assets for ShqipKosovaTV

These PNG icons are referenced by the app and OTA JSON through public raw GitHub URLs:
`https://raw.githubusercontent.com/TV-shqipp/tv-config-app/main/icon/<filename>.png`

Keep this folder at the repository root when publishing `tv-config-app`. The images are custom channel tiles built from each channel or group name and monogram; they are not official broadcaster logo files. The JSON does not use device-local paths.
